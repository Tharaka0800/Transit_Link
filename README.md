## Setup Instructions

1. Install dependencies:
   npm install

2. Run the app:
   npx expo start

3. Scan the QR code with Expo Go app (phone) or press `w` for web.

## Tech Stack

- React Native (Expo)
- React Navigation
- AsyncStorage (Local Storage)
- React Native Maps
